# MilkyWay

MilkyWay is a responsive, multi-page website that offers a simple introduction to the Solar System. The home page provides an interactive menu for exploring the Sun and the eight planets, while each celestial body has its own page with a short description and key facts.

## Features

- Interactive animated navigation menu
- Dedicated pages for the Sun and all eight planets
- Quick facts about each celestial body
- Responsive layout for desktop and mobile screens
- Space-themed design with a starry background and hover effects
- Lightweight and dependency-free

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox and Grid
- CSS transitions and responsive media queries

## Getting Started

No installation or build process is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/milky-way.git
   ```

2. Open the project directory.

3. Open `index.html` in your browser.

You can also run the project with a local development server, such as the Live Server extension for Visual Studio Code.

## Deployment with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public URL after the deployment finishes.
